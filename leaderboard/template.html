PrefixSim algorithm leaderboard

Every eviction algorithm PrefixSim drives, replayed over two LLM-serving traces at several KV-cache sizes, through the prefixsim Python package. Each run is one algorithm at one size over the whole trace. Higher is better for every metric.

    How these were run

    Defaults of prefixsim.simulate: pinning on, replay_order="deepest-first", block_id="prefix", the cost model shown above. Each run is its own process; a run that crashed or passed the time limit shows as "—" (hover it for why). The oracles (belady, belady_compute, session_belady) read each block's next access from the trace, so they bound what an online algorithm can reach; their lines are dashed.
